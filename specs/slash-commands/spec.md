# MewCode 斜杠命令注册与分发 Spec

## 背景

当前交互式 CLI 直接在输入入口判断少量特殊字符串；`/plan`、`/do` 仍是一次性请求前缀，缺少统一注册、别名校验、帮助和补全。清屏、状态查询、上下文压缩等确定性操作不应进入 Agent。

本功能建立统一的斜杠命令入口，使命令在本地快速、确定地执行；普通输入继续交给 AI。命令实现与具体终端渲染解耦，并提供持久的 `[DEFAULT]/[PLAN]` 模式反馈。

除 `/compact` 必要的摘要调用和 `/review` 外，其余斜杠命令不发起模型请求。成功标准是：所有内置命令通过统一机制注册和分发；冲突启动即失败；模式、帮助、错误提示和 Tab 补全均可直接观察和测试。

## 目标

- 建立统一、可枚举、可测试的命令目录，集中管理命令元数据和执行行为。
- 在用户输入进入 Agent 前完成确定性的斜杠命令识别与分流。
- 让高频本地操作绕过 Agent Loop，降低延迟并避免无意义的上下文占用。
- 提供持久的计划/默认模式切换及明确的状态栏反馈。
- 提供别名、帮助和 Tab 补全，提升命令的可发现性和输入效率。
- 在保留现有交互行为的同时，为后续 Skill 系统扩展命令能力建立边界清晰的基础。

## 功能需求

- F1：系统维护统一命令目录。每条命令登记名称、别名、简短描述、用法示例、执行类型，以及可选的参数提示、隐藏标记和执行行为。
- F2：启动时对大小写归一化后的名称和别名做全量冲突检查。名称—名称、名称—别名、别名—别名任一撞名都立即终止启动，并指出冲突项。
- F3：输入去除首尾空白后，为空则直接返回；不以 `/` 开头则作为普通消息交给 AI；斜杠后的第一个空白分隔命令名与参数，命令名大小写不敏感。
- F4：未知命令和参数不合法的命令都不得发送给 AI；界面显示明确错误、正确用法及 `/help` 引导。
- F5：命令分为三类：本地操作、界面状态操作、预设提示词。类型作为命令元数据的一部分，可由帮助和补全界面展示。
- F6：命令只能通过统一界面能力显示消息、发送用户消息、切换模式、查询 Token/上下文状态和刷新状态栏，不依赖具体渲染框架。
- F7：回车入口先执行命令分流。成功或失败的本地/界面命令均不进入对话历史；预设提示词命令把展开后的固定提示词作为用户消息发送，原始斜杠文本不进入对话。
- F8：Tab 仅补全第一个命令词。完整别名优先归一化为规范命令名；单个匹配直接补全并追加空格，多个匹配显示包含名称、描述和参数提示的菜单。隐藏命令不参与补全。
- F9：`/help` 列出十个非隐藏内置命令；`/help <名称或别名>` 显示单条命令的描述、用法、类型、别名和参数提示。隐藏命令不在总览中，但可被显式查询。
- F10：`/compact` 执行现有手动上下文压缩并显示压缩结果，不进入 Agent Loop。无需摘要时完全本地完成；需要摘要时允许调用 Provider，并显示可获得的 Token 用量。
- F11：`/clear` 只清空终端显示，不清除对话、上下文、会话、Token 状态或模式。
- F12：`/plan` 进入持久计划模式，`/do` 返回持久默认执行模式；两者均不接受参数、不调用 AI。启动固定为 `[DEFAULT]`，切换后状态栏立即显示 `[PLAN]` 或 `[DEFAULT]`。
- F13：模式仅在当前进程内保持；隐藏的 `/new` 不改变模式，只有 `/plan` 和 `/do` 可以切换。
- F14：`/session` 只显示当前会话 ID、消息数、新建或恢复状态以及上下文概况，不切换或新建会话。
- F15：`/memory` 只显示项目级和用户级记忆的条目数、索引路径及后台更新状态，不展示记忆正文，也不提供编辑或删除。
- F16：`/permission` 只显示当前权限模式、已加载规则来源及优先级，不允许运行时修改权限。
- F17：`/status` 汇总当前 Agent 模式、Provider/模型、权限模式、会话 ID、最近一次 Token 用量、当前上下文概况和后台记忆状态；信息不可用时明确标记，不主动发起网络健康检查。
- F18：`/review` 不接受参数，将固定的“审查当前工作区未提交变更”提示词发送给 AI，聚焦缺陷、回归、安全和测试缺口，只报告问题、不修改文件。本次请求强制只读，但不改变持久模式。
- F19：十个可见命令采用以下别名：
  - `help`：`h`、`?`
  - `compact`：`cmp`
  - `clear`：`cls`
  - `plan`：`p`
  - `do`：`d`
  - `session`：`sess`
  - `memory`：`mem`
  - `permission`：`perm`
  - `status`：`st`
  - `review`：`rev`
- F20：现有 `/new` 迁入统一命令目录，作为隐藏兼容命令继续新建会话；它不出现在帮助总览和 Tab 补全中。
- F21：`exit`、`quit`、`退出` 继续按现有方式结束程序，不纳入斜杠命令目录。

## 非功能需求

- N1：注册、解析、别名归一化、帮助查询和补全结果必须确定；同一注册集合与输入始终产生相同结果。
- N2：除 `/review` 和 `/compact` 必要的摘要调用外，其他斜杠命令不得发起 Provider 请求，也不得把内容加入模型上下文。
- N3：注册和分发层不得依赖具体终端框架；命令行为可通过替代界面实现进行自动化测试。
- N4：名称、别名、大小写、空白、未知命令和非法参数必须具有一致且可测试的处理规则。
- N5：注册冲突属于启动期程序错误，必须立即失败；单个命令运行失败则显示安全错误并保持交互循环可继续使用。
- N6：帮助、状态、会话、记忆和权限输出不得泄露 API Key、权限规则内容、记忆正文或其他敏感配置值。
- N7：命令识别、帮助和补全不得等待网络；本地状态查询不得因 Provider 或 MCP 不可用而阻塞。
- N8：保留普通消息、现有压缩、新建会话、退出命令、中文输入及 Ctrl+C/Ctrl+D 的既有行为。
- N9：补全菜单和状态栏必须正确支持中文及终端宽字符显示。
- N10：新增行为必须具备单元测试；输入分流、模式切换和提示词命令至少具备集成测试。

## 不做的事

- 不支持用户自定义命令、项目命令、运行时注册、动态重载或插件发现；留给后续 Skill 系统。
- 不支持根据参数动态拼接提示词；`/review` 使用固定提示词且不接受参数。
- 不引入命令级权限规则、审批或单独沙箱；现有 Agent 工具权限系统保持不变。
- 不提供会话列表、搜索、切换或删除；`/session` 仅查看当前会话。
- 不提供记忆正文浏览、编辑、删除或手工触发更新。
- 不提供运行时权限模式切换或权限规则编辑。
- 不主动检查 Provider 或 MCP 服务健康状态。
- 不实现完整全屏 TUI、鼠标交互或复杂窗口布局；仅增加命令补全菜单和模式状态栏。
- 不持久化 `[DEFAULT]/[PLAN]` 模式，也不随恢复会话恢复模式。
- 不支持命令串联、管道、重定向、引号解析或 shell 风格参数语法。
- 不为命令参数提供 Tab 补全；本阶段只补全命令名称。
- 不改变现有上下文压缩算法、会话存储格式、记忆格式或权限配置格式。

## 验收标准

- AC1：命令目录可枚举十个可见命令和隐藏 `/new`；每项都具有名称、别名、描述、用法、类型、隐藏状态和可执行行为，可选参数提示按定义存在。（覆盖 F1、F5、F19、F20）
- AC2：分别构造名称—名称、名称—别名、别名—别名以及仅大小写不同的冲突，程序均在进入交互循环前失败并指出冲突项；无冲突时正常启动。（覆盖 F2）
- AC3：空白输入不产生动作；普通输入只发送给 AI；`/HELP status` 能按 `/help status` 解析；命令后的参数去除外围空白但保留内部内容。（覆盖 F3）
- AC4：未知命令、仅输入 `/`、以及给无参数命令附加参数时，都不调用 AI，并显示错误、正确用法和 `/help` 引导。（覆盖 F4）
- AC5：通过替代界面实现执行各类命令，能够观察到本地操作、界面状态更新和预设用户消息三个不同分发路径，命令行为不要求真实终端存在。（覆盖 F5、F6、F7）
- AC6：十个可见命令的全部规范名称与约定别名均能大小写不敏感地命中同一命令。（覆盖 F3、F19）
- AC7：`/cl` + Tab 直接补成 `/clear `；`/s` + Tab 显示 `/session` 与 `/status` 菜单；`/p` + Tab 优先补成 `/plan `；隐藏 `/new` 不作为任何补全候选。（覆盖 F8、F19、F20）
- AC8：`/help` 只列出十个可见命令；`/help st` 显示 `/status` 的规范名称、别名、类型、描述、用法和参数提示；`/help new` 可显式查看隐藏兼容命令。（覆盖 F9）
- AC9：`/compact` 不进入 Agent Loop；无需摘要时完全本地完成，需要摘要时只调用压缩所需 Provider，并显示压缩前后上下文估算及可取得的 Token 用量。（覆盖 F10）
- AC10：执行 `/clear` 后终端可见输出被清除，但会话 ID、消息历史、上下文、Token 状态和当前模式均保持不变。（覆盖 F11）
- AC11：启动状态栏显示 `[DEFAULT]`；`/plan` 后立即显示 `[PLAN]`，后续普通输入以只读计划模式发送；`/do` 后恢复 `[DEFAULT]`，后续普通输入按默认执行模式发送。（覆盖 F12）
- AC12：重启程序时模式恢复为 `[DEFAULT]`；当前处于 `[PLAN]` 时执行隐藏 `/new`，新会话仍保持 `[PLAN]`。（覆盖 F13）
- AC13：`/session` 显示当前会话 ID、消息数、新建或恢复状态及上下文概况，不产生新会话、不切换会话，也不调用 AI。（覆盖 F14）
- AC14：`/memory` 显示项目级和用户级条目数、索引路径及后台状态；输出不含任何记忆正文，且不调用 AI。（覆盖 F15）
- AC15：`/permission` 显示当前权限模式、实际加载的规则来源和优先级；执行前后权限行为不变。（覆盖 F16）
- AC16：启动后立即执行 `/status` 时，不可用的 Token 信息被明确标记；完成一次模型请求后再次执行，输出包含当前模式、Provider/模型、权限模式、会话 ID、最近 Token 用量、上下文概况和记忆后台状态，且不产生网络请求。（覆盖 F17）
- AC17：在工作区存在未提交变更时执行 `/review`，发送的是固定审查提示而不是字面量 `/review`；本次 Agent 只能使用只读能力，输出聚焦问题且工作区无新增修改，完成后持久模式不变。（覆盖 F18）
- AC18：`/new` 仍能关闭当前会话并创建新会话，但不会出现在帮助总览或补全菜单；它产生的本地操作不进入对话历史。（覆盖 F20）
- AC19：`exit`、`quit`、`退出`、Ctrl+C、Ctrl+D 和普通中文消息继续保持既有行为，不被命令目录误处理。（覆盖 F21）
- AC20：命令执行中出现可预期错误时，界面显示安全错误且下一次输入仍可处理；错误输出不包含 API Key、权限规则正文、记忆正文或敏感配置值。（覆盖 N5、N6）
- AC21：自动化测试覆盖注册冲突、解析、别名、帮助、补全、三类分发、全部内置命令、模式状态栏和异常恢复。（覆盖 N1—N10）
- AC22：端到端场景依次执行 `/p`、普通任务、`/status`、`/review`、`/d`、`/clear` 和 `/help status`；可观察到模式正确切换、普通任务进入计划模式、审查单次只读、状态查询不联网、清屏不丢状态、帮助内容正确，且只有普通任务和 `/review` 触发 Agent。（覆盖 F1—F21）
